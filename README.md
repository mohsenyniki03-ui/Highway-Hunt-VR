# Highway-Hunt-VR

A Virtual Reality racing game built with Unity.

## Overview

Highway-Hunt-VR is an immersive VR racing experience that puts players behind the wheel in high-speed highway chases. Built with Unity and designed for VR headsets, the game offers an adrenaline-pumping racing experience.

## Features

- **VR Support**: Full virtual reality experience with head tracking and motion controls
- **Highway Racing**: Race through dynamic highway environments
- **Multiple Vehicles**: Choose from a variety of vehicles with unique handling characteristics
- **Immersive Audio**: 3D spatial audio for a realistic racing experience

## Requirements

### Development Requirements
- Unity 2022.3 LTS or later
- XR Plugin Management
- OpenXR Plugin or Oculus XR Plugin
- Compatible VR headset (Meta Quest, HTC Vive, Valve Index, etc.)

### Hardware Requirements
- VR-ready PC (for PC VR)
- Compatible VR headset
- VR controllers

## Getting Started

### Clone the Repository
```bash
git clone https://github.com/mohsenyniki03-ui/Highway-Hunt-VR.git
```

### Open in Unity
1. Install Unity Hub and Unity 2022.3 LTS
2. Open Unity Hub and add the project
3. Open the project in Unity
4. Configure XR settings for your target VR platform

## Project Structure

```
Highway-Hunt-VR/
├── Assets/
│   ├── Scripts/       # Game logic and VR interactions
│   ├── Scenes/        # Game scenes
│   ├── Prefabs/       # Reusable game objects
│   ├── Materials/     # Materials and shaders
│   ├── Models/        # 3D models
│   ├── Audio/         # Sound effects and music
│   └── XR/            # VR-specific assets
├── Packages/          # Unity package dependencies
├── ProjectSettings/   # Unity project settings
└── README.md
```

## Controls

| Action | VR Controller |
|--------|---------------|
| Accelerate | Right Trigger |
| Brake | Left Trigger |
| Steer | Controller rotation or thumbstick |
| Look Around | Head movement |
